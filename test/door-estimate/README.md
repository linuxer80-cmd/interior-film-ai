# 문 사진 수동 등록·단가 비교 테스트

- 화면: `/test/door-estimate` (기존 관리자 로그인 사용)
- 소비자: `/test/door-estimate?company=<company-slug>`
- 최초 준비: 앱 Supabase SQL Editor에서 `setup.sql` 실행.
- 내 업체 연결 → 샘플 직접 업로드 → AI 분석 확인 → 1개 단가·시공 범위 입력 → DB 저장 → 비교할 문 사진 업로드.
- 업체당 최대 10장. 한 장부터 비교 가능. 기존 시공 DB는 사용하거나 변경하지 않음.
- 사진은 work-photos/door-test/<company>/<id>.jpg에 저장. 분석과 단가는 door_test_uploads에 저장.
- 분석한 사진의 해시·업체·사용자를 서명해 저장 요청 검증. 분석 후 단가 저장은 AI를 재호출하지 않음. 서명은 한 시간 유효.
- 구조 특징 기반 비교이며 이미지 임베딩/픽셀 기반 검색은 아님. AI에 가격을 전달하지 않음.
- 종류·개폐방식·문짝 수·시공 범위 일치 후보만 고정 가중치 비교. 65점 미만은 보류. 점수는 확률이 아님.
- 가장 가까운 샘플 단가 × 요청 수량. 크기·자재·보수·부가세 차이는 미보정.
- RLS 활성화, 클라이언트 직접 DB 접근 차단, 서버에서 업체 관리자 검증. AI 호출은 기존 사용량 제한 적용.
- 검증: `node --test test/door-estimate/*.test.mjs`

## 환경 상태
Supabase MCP 연결 시간 초과로 테이블 적용과 실데이터 저장 검증은 완료하지 못함. 샘플은 사용자가 직접 업로드하도록 구현했으며 임의 사진·단가는 없음.
