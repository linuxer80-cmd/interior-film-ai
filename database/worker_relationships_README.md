# 직원·협력 시공자 연결 및 등록 일당 (1·2차)

## 적용

1. 기존 labor_market_workflow.sql, labor_market_consistency.sql 적용 환경에서 `worker_relationships.sql` 전체를 Supabase SQL Editor로 실행합니다. 한 트랜잭션이며 재실행할 수 있습니다. 기존 구인 함수가 예상과 다르면 변경을 중단하므로 오류를 무시하지 마세요.
2. 앱 코드를 배포합니다. SQL 미적용 상태에서는 기존 조회·정산은 유지되지만 새 연결·등록 일당 채용은 DB 적용 안내와 함께 차단됩니다.
3. 관리자 시공자 관리의 **직원·협력 시공자 연결 관리**에서 명단의 사람과 관계를 선택하고 초대 링크를 복사합니다. 링크 유효기간은 7일입니다.
4. 시공자는 로그인 후 초대를 명시적으로 수락합니다. 신규 가입은 개인설정에서 마친 후 초대 링크를 다시 엽니다.
5. 관리자는 수락한 이메일이 실제 초대한 사람의 계정인지 별도로 확인한 뒤 승인합니다. 이메일 문자열·이름·전화번호 일치만으로 계정을 연결하지 않습니다. 기존 연결 계정은 다른 계정으로 바꿀 수 없습니다.

## 금액 및 기록

- 공고 금액은 모집 기준입니다. 새 채용은 관리자 화면에 표시된 본인 등록 일당으로 확정합니다. 확인 중 일당이 변경되면 새로고침 후 다시 확인해야 합니다.
- 협력 관계 연결 이후 신규 날짜 배정에는 등록 일당 스냅샷을 저장합니다. 동일 현장·시공자·날짜를 재저장해도 금액을 다시 정하지 않습니다.
- 직원 급여 및 기존 관계 미지정 시공자 급여는 기존 기준을 유지합니다. 기존 배정·계약을 소급해서 재평가하지 않습니다.
- 관리자 매출·인건비 지급과 시공자 월 근무금액에서 동일한 확정 단가를 사용합니다. 팀장 수당은 기존 별도 기준을 유지합니다.
- 거래 종료는 workers.is_active=false로 새 접근·배정을 중지합니다. user_id, 현장, 지급 및 확정 단가 기록은 삭제하지 않습니다.
- 직원의 업무 홈에서는 구인 탐색 메뉴를 숨깁니다. 개인설정에서 본인이 구인구직으로 이동할 수 있으며 기존 배정·지원 관련 알림은 유지합니다.
