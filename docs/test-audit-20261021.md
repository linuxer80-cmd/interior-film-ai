# 2026-10-21 관리자 연결 수정 및 테스트 점검

## 완료
- 관리자 오늘 시공 바로가기를 현장 팀 채팅으로 통일. 개인 시공은 기존 시공자 홈에서 진행.
- 시공자 배정 바로가기: 날짜가 있으면 시공자 단계, 없으면 날짜 단계. 날짜 확인 바로가기는 날짜 단계로 초기화.
- 회귀 테스트에서 두 연결 및 저장하지 않은 입력 보호 확인.
- 누락된 PGlite 개발 의존성 고정 설치. 로컬 테스트 DB만 사용.
- 제거된 관리자 내부 시공 화면을 요구하던 테스트 수정.
- 캘린더 Strict Mode 테스트의 초기 효과 실행 순서 보완.
- 견적 훅 테스트에 실제 의존성 mergeProfiles와 performance, console.info 제공.
- 인력시장 라우트 테스트에 배지 조회 의존성 제공.

## 견적 금액 누락 후속 점검
- 합계 110,000원→0원 실패는 필수 항목명·수량 없는 테스트 입력 때문으로 확인. 필수 필드가 채워진 입력으로 세 가지 부가세 계산 검증 통과.
- 실제 부위별 견적 컴포넌트의 항목 추가 및 입력 이벤트 재현: 기존 200,000원 + 추가 150,000원, 부가세 별도 385,000원. 추가 수량 2로 변경하면 550,000원.
- 새 행이 파일 출력용 데이터와 저장 전 검증 결과에 포함되는지 확인. 미입력 단가는 미완성 안내 유지.
- 인건비·자재비 견적의 직접 금액 입력과 새 행의 단가 계산도 합산되는지 검증. 필수 값이 비어 있는 미확정 행은 기존 정책대로 제외.
- 운영 계정의 기존 견적 저장·재조회 및 실제 파일 렌더링은 이번 테스트 범위 밖. 사용자 과거 사례와 동일 원인이라고 단정하지 않음. 제품 계산 코드는 변경하지 않음.
- 후속 전체 결과: 721개 중 통과 676, 실패 14, 건너뜀 31. 기존 노무비 단위 관련 1개 실패는 별도 항목으로 유지.
