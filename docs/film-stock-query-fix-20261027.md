# 자재 조회 지연 개선

- 제품 카드 조회는 `materialId`로 해당 제품의 재고만 조회한다. 현장/업체/활성 자재 검증은 서버에서 한다.
- 방염 구분을 재고 RPC 응답에 포함하여 후속 DB 요청 3개를 없앴다. 이전 DB 버전에 대한 호환 경로는 유지한다.
- 반출·반납 이력은 전체 현장 범위를 유지하여 다른 자재의 롤 추적 상태가 사라지지 않는다. 삭제된 예정 자재는 재고 연결에서 제외한다.
- 같은 화면의 중복 조회를 합치고 최근 5초 응답만 화면 내부에서 재사용한다. 수동 새로고침은 새 응답을 요청하며 저장/화면 종료 시 무효화한다.
- 로그인 확인 또는 네트워크가 멈추어도 15초 후 조회 상태를 해제하고 재시도를 안내한다. 늦게 도착한 응답은 최신 상태를 덮어쓰지 않는다.
- 조회 전 반납 개수는 0 대신 `확인 중`/`조회 필요`로 표시한다. 실패한 조회의 이전 데이터로 저장하지 못하게 한다.

## 확인

- 송도해모로월드뷰 GW952 비방염: 반출 누계 70m, 반출 이력 2건 정상. DB 변경 전후 현장 전체 반출·반납 이력 해시 동일.
- 같은 현장에서 `EXPLAIN ANALYZE`로 측정한 DB 실행 시간: 기존 전체 조회 890.732ms → 제품 지정 조회 72.632ms. 단일 측정이며 휴대폰 화면 전체 로딩 시간은 아니다.
- 전체 테스트 963개 통과, 운영 빌드 통과.
- 지연/재시도, 중복 조회, 취소 후 늦은 응답, 제품/업체별 범위, 작업자 원가 비공개, 반복 반납 멱등성, 구버전 호환 검증.
- RPC는 security invoker, 빈 search_path, service_role 전용 실행 권한 유지. DB 보안·성능 점검에 새 항목 없음.
- 실제 고객 알림이나 재고 수량 변경 없이 조회 및 배포를 검증한다. 실제 모바일 로그인 세션의 네트워크 상황은 직접 재현하지 못했다.
