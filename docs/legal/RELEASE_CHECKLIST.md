# 필름장이 약관 정식 적용 전 확인사항

## 현재 반영 범위
- 이용약관, 개인정보처리방침, 공통 사례 활용 선택 동의문 초안.
- 고객지원에서 초안 열람. noindex 적용. 시행일 미확정.
- 동의 화면 예시는 기본 미선택·비활성. 동의 저장/권리 이전/공개 범위 변경 없음.
- DB 리전 서울(ap-northeast-2)을 확인했으나 해외 지원/로그/재위탁까지 국내 처리라고 확정하지 않음.

## 정식 공개 전에 필요한 운영 확인
- 운영자 사업자등록번호·사업장 주소·지원 연락처 및 개인정보 담당 책임자/부서 확정.
- 실제 수집 항목별 필수/선택, 처리 근거, 사용 목적, 보유기간 확정.
- Supabase, Vercel, OpenAI, 토스페이먼츠, 카카오 및 실제 발송업체의 법인명·처리 역할·연락처·재위탁 확인.
- 국외 이전 국가·항목·시점·방법·보유기간·근거·거부 방법/영향 확인. 별도 동의 필요한 경우 분리.
- 출퇴근 위치정보 저장 범위·기간 및 적용되는 위치정보 관련 절차 확인.
- 개인정보 열람·정정·삭제·철회 요청 본인확인과 운영 담당 절차 확정.
- 회원탈퇴, 업체종료, 시공자 연결해제 구분. 원본·DB·Storage·캐시·검색 인덱스·백업 삭제 절차 검증.
- 현재 공개 고객페이지와 유사 사례 검색의 전체 데이터 흐름 확인. 새 동의를 과거 데이터의 근거로 소급 사용 금지.

## 동의 기능 구현 기준
- 활성 업체 관리자만 업체 자료 이용허락 가능. 역할은 서버 profiles 기반 확인.
- 필수 약관과 선택 활용 동의는 별도. 초기 미동의. 기본 기능 제한 금지.
- 서버가 부여하는 동의문 버전·시각, 행위자 계정·업체, 대상 범위·현재 상태와 변경 이력 저장.
- 회사별 RLS/서버 권한 검증, 중복 제출 및 철회 경쟁 처리.
- 새로운 동의로 과거 철회 자료를 자동 재공개하지 않기.
- 탈퇴 후에도 이메일로 자료 식별·철회 가능하도록 자료 추적 설계.

## 공개 사례 처리 기준
- 이용허락과 별도로 개별 자료의 권리·비식별 검토 상태 필요.
- 등록한 원본을 자동으로 공동 풀에 복사하지 않음.
- 승인된 별도 파생본만 사용; 이름·주소·연락처·계좌·얼굴·차량번호·EXIF·자유서술 식별정보 검토.
- 단순 가명처리를 익명처리로 표시하지 않음. 재식별 가능하면 공개 제외/별도 적법 근거 검토.
- 철회 시 파생사진·보고서 추출값·썸네일·임베딩·캐시 및 검색 경로에서 제외.
- 원본 보고서의 일괄 양도·영구 보관, 광고/SNS 홍보, 모델 학습은 본 허락 범위 밖.
- 자동화가 준비되기 전에는 동의 수집과 공동 활용을 활성화하지 않음.
